# StockSense: requirements
#
# StockSense is a Node.js (Next.js) project, not a Python project.
# The packages below are installed automatically from package.json with:
#     npm install
# Do NOT run "pip install -r requirements.txt".

# ---------------------------------------------------------------
# System requirements
# ---------------------------------------------------------------
Node.js >= 18.18        (tested on 24.x)  https://nodejs.org
npm >= 9                (comes with Node.js)
Git                     https://git-scm.com
A modern browser        (Chrome, Edge, Firefox)
Gmail account with an App Password (only for password-reset OTP emails)
# No database server needed: SQLite runs from a local file (prisma/dev.db)
